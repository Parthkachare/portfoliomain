Design an interactive gamified web experience called **“Escape the Developer’s Portfolio”** for a developer named **Parth Kachare**.

The experience should feel like a futuristic hacker-style interface where visitors must solve puzzles to unlock the developer’s portfolio.

STYLE:

* Dark futuristic UI
* Black background with neon blue and purple accents
* Glassmorphism cards
* Subtle glow effects
* Modern tech startup aesthetic
* Clean grid layout
* Fonts: Inter for UI and JetBrains Mono for code sections

PLATFORM:
Responsive website (desktop first, mobile adaptive)

SCREENS TO DESIGN:

1. INTRO / LANDING SCREEN
   Title: “Escape the Developer’s Portfolio”
   Subtitle: “Solve the challenges to unlock Parth’s work.”
   Elements:

* Glowing “Start Challenge” button
* Animated code background
* Small leaderboard preview
* Microinteraction hover effects

2. LOCKED PORTFOLIO SCREEN
   Show blurred portfolio sections:

* Projects
* Skills
* About
* Contact

Overlay message:
“Portfolio Locked — Complete the challenges to gain access.”

3. PUZZLE SCREEN 1 — FIND THE HIDDEN ELEMENT
   A UI dashboard layout with hidden clickable elements.
   Instruction text:
   “Find the hidden access key.”

4. PUZZLE SCREEN 2 — FIX THE CODE
   Display a code snippet inside a developer-style code editor panel.

Example bug:
function add(a,b){
return a - b
}

Question:
“What is the correct fix?”

Show multiple-choice options.

5. PUZZLE SCREEN 3 — LOGIC RIDDLE
   Minimal card with riddle text and input box.

Example:
“I speak without a mouth and hear without ears. What am I?”

Answer field + submit button.

6. PUZZLE SCREEN 4 — PASSWORD DECODER
   Encrypted text displayed in a cyber-style panel.

Example cipher:
Khoor Zruog

Hint: “Shift cipher +3”

Input field for decoded answer.

7. SUCCESS SCREEN — ACCESS GRANTED
   Large animated message:
   “ACCESS GRANTED”

Reveal unlocked sections:

* Projects
* Skills
* About
* Contact

Add CTA button:
“Explore Portfolio”

8. SCORE RESULT SCREEN
   Show:

* Completion time
* Score
* Rank on leaderboard

Example layout:
Your Score: 92
Leaderboard Rank: #3

9. REWARD SCREEN
   Gamified reward system:

Top 3 players → Free UI/UX consultation
Top 10 players → 20% project discount

Display reward card with badge icons.

Button:
“Claim Your Reward”

10. REWARD CLAIM FORM
    Simple lead capture form with fields:

* Name
* Email
* Company / Project Name
* Service Needed (dropdown)

Dropdown options:
Website Development
Mobile App Development
UI/UX Design
Startup MVP

Submit button: “Claim Reward”

11. SHARE SCREEN
    Message:
    “Challenge your friends to beat your score.”

Buttons:

* Share on LinkedIn
* Share on WhatsApp
* Copy Challenge Link

COMPONENTS TO CREATE:

* Puzzle card component
* Leaderboard row component
* Neon button styles
* Glass panel containers
* Code editor UI component
* Reward badge cards

INTERACTIONS:

* Hover glow effects
* Puzzle success animations
* Unlock transition animation
* Leaderboard highlight effect

GOAL:
The design should feel like a **tech startup product experience rather than a normal portfolio**, encouraging users to explore, play the game, and discover Parth’s projects while unlocking rewards.
